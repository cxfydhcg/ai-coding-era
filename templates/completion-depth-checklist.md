## D1 主路径正确

- [ ] 每条接受标准都有对应的自动化或记录性验证
- [ ] 验证的是需求描述的行为，不是实现的复述
- [ ] 典型输入下的结果被独立确认过（不是只看 Agent 的自述）

## D2 边界与失败路径

- [ ] 空值、缺失字段、超长输入、非法格式
- [ ] 边界数值：0、负数、最大值、精度与取整
- [ ] 重复提交、并发请求、竞态与幂等
- [ ] 依赖失败：超时、网络错误、部分成功、重试与退避
- [ ] 权限不足、未登录、越权访问、租户隔离
- [ ] 界面状态闭环：loading、空、错误、重试、禁用、部分失败
- [ ] 失败是可见的，不是被静默吞掉
- [ ] 测试的 oracle 不是由写实现的同一个会话推导出来的

## D3 在真实系统中可运行

- [ ] 真实数据量下的性能，包含 N+1 与慢查询
- [ ] 历史数据与脏数据兼容
- [ ] 迁移、双写双读、回填与回滚路径
- [ ] 可观测性：日志、指标、告警、trace 或审计
- [ ] 排查入口存在，出问题时能定位
- [ ] 时区、单位、货币、本地化与可访问性
- [ ] 多用户视角验证（非管理员、其他租户、其他设备或语言）
- [ ] 运行配置、权限配置与告警阈值已同步更新
- [ ] 当前状态文档与 runbook 与新行为一致
- [ ] 与其他切片的集成行为有明确责任人并被验证

## D4 结果被验证

- [ ] 目标指标或用户证据显示预期变化
- [ ] 生产观察窗口已完成，异常已处理
- [ ] 旧路径、双写、兼容层、feature flag、迁移脚本和死代码已删除，或有 owner 与删除 gate
- [ ] 学到的结论已回写到测试、文档或 decision record
