# 任务管理

AI 可以快速执行清晰任务，也可以极快地放大模糊任务。任务管理的目标不再只是分配人力，而是建立一条从问题发现、授权、实现、验证到生产观察的证据链。

## 任务的基本单位是“结果契约”

一个可执行任务应回答：

| 字段 | 问题 |
| --- | --- |
| Outcome | 哪个可观察结果需要改变？ |
| Evidence | 什么事实证明问题存在？ |
| Scope | 哪些内容允许改变，哪些明确不做？ |
| Constraints | 哪些契约、风险和兼容要求不可破坏？ |
| Acceptance | 何时可以判断任务完成？ |
| Verification | 用什么检查获得证据？ |
| Owner | 谁对决策和最终结果负责？ |
| Authority | Agent 可以自主做到哪一步？ |

模板见 [任务契约](../templates/task-contract.md)。

## 按工作形态路由，而不是按大小路由

发现一个问题后，先判断它需要哪种协调方式：

| 工作形态 | 路由 |
| --- | --- |
| 当前任务内可以安全完成并验证 | Fix now |
| 问题真实、可独立描述，但当前不应扩大范围 | Backlog |
| 需要共享范围、阶段、跨团队协议、rollout 或 release gate | Requirement / Initiative |

一个小改动也可能有很高的发布风险；一个大型机械重构也可能不需要长篇 specification。流程重量应由不确定性、依赖、不可逆性和协作成本决定。

## 工作项生命周期

```text
Discovered
    ↓ triage
Deferred ─────→ Retired / Invalid
    ↓ approve
Contracted
    ↓ implement
Implemented
    ↓ production evidence
Observed
    ↓ cleanup or supersede
Retired
```

### Discovered

只有证据和初步判断，还没有自动获得修改权限。Agent 发现的问题也从这里开始。

### Deferred

问题被确认，但不属于当前工作。条目必须足够完整，使未来的人或 Agent 不依赖原聊天也能继续。

### Contracted

目标、范围、接受标准、责任人和关键风险已批准，工作可以进入 Ready。

### Implemented

代码已经合并或制品已经产生，但需要生产证据的任务还不能因此自动关闭。

### Observed

预期行为在目标环境中得到验证，重要假设有实际证据支持。

### Retired

任务被替代、取消，或相关临时机制已安全删除。保留必要的历史原因，清除不再有用的活动上下文。

## 一个有效事实源

同一工作项应拥有稳定 ID，例如 `AI-042`。它可以在不同阶段链接到 backlog、requirement、PR 和发布记录，但同一阶段只有一个 active canonical record。

当 backlog 被提升为正式任务时，原条目应替换为链接或移除，而不是复制一份后让两边独立演化。

## Ready 与 Done

### Ready 的最低条件

- 结果和责任人明确；
- 关键证据可访问；
- 依赖和阻塞已知；
- 接受标准可以验证；
- 授权边界明确；
- 风险与流程重量匹配。

### Done 的最低条件

- 接受标准已逐项满足；
- 要求的自动与人工验证有记录；
- scope deviation 已解释并获得授权；
- 当前状态文档已同步；
- rollout、监控和回滚要求已满足；
- 新发现的范围外问题已明确处置；
- 不再需要的临时 artifact 已清理或设置淘汰条件。

## 控制在制品数量

AI 提升实现能力后，团队很容易启动太多工作。WIP 过高会把瓶颈转移到审查、集成和发布，并制造大量过期上下文。

推荐做法：

- 对“实现中”和“待审查”分别设置 WIP 限制；
- 审查队列拥堵时，优先完成和验证，而不是继续生成；
- 一个 owner 同时承担的高风险任务数量应很少；
- 定期关闭失效任务，合并重复条目，淘汰不再有价值的计划。

## AI 发现问题时的处置

```text
这是一个真实问题吗？
  ├─ 否：说明为什么不应保存
  └─ 是
      ├─ 当前范围内可安全完成：提出或执行 fix
      ├─ 当前不应处理：生成可独立执行的 backlog 条目
      └─ 需要协调与批准：建议提升为 requirement
```

关键原则是：自动发现可以提高覆盖率，但不能自动扩大任务权限。
